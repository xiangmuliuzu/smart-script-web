# App 用户与创作者筛选修复

下拉选择后原本没有触发查询；点击搜索时，作者能力的 HTTP 字符串 true/false 又被原样绑定到 MySQL，true 被转换成 0，导致已开通筛选匹配错误。

前端下拉选择、关键词回车和清空触发查询；搜索去除关键词两侧空格，重置全部条件并回到第一页。仅最新一轮请求能够更新结果和加载状态。后端配套修复把作者能力转换为 Boolean，并在异常参数被拒绝时清理分页 ThreadLocal。

验证：

- `node --test tests/app-user-filter.test.js`：3 项通过，包含保留 false、重置与过期响应覆盖。
- `npm run gate`：57 项测试、静态检查与生产构建通过。
- 真实浏览器加载现有 UserManage.vue 和请求封装，使用本机后端与独立测试身份，验证作者能力、状态、最新实名状态、搜索、回车、关键词空白及重置。测试账号和临时角色已清理。

后端需包含同时提交的 AppUserAdminService 参数规范化修复；本次不修改管理权限、数据库结构或界面布局。
