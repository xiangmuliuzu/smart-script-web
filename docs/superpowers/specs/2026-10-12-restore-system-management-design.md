# 恢复完整系统管理模块

用户确认恢复完整若依系统管理模块，初始化和升级脚本按当前目录更新。

恢复七个页面：用户管理、角色管理、菜单管理、部门管理、岗位管理、字典管理、参数设置。前六个历史页面与接口中已有的文件从删除前版本恢复，部门页面复用现有若依部门接口补齐。显式组件白名单恢复七个 component 标识，使用后台动态菜单注册 `/system/**` 路由。

系统管理作为独立根目录，排序在业务目录之后。操作日志、登录日志继续位于数据统计；公告继续位于平台运维管理的消息与公告。参数页对验证码参数提供开启、关闭开关，保存通过原若依参数接口立即更新配置缓存。保留参数备注和内置类型，内置参数不可从页面删除。

正式数据库入口仍为 `sql/smartscript_full_init.sql`。新库直接创建系统管理目录与七个页面；已有库在第 13 部分恢复目录、页面和按钮权限。保留已有系统根目录 ID、自定义子菜单、受限角色的逐项授权和配置值。仅超级管理员角色恢复完整系统管理授权，已有页面授权角色补齐系统父目录。

旧菜单清理逻辑只处理已迁移的公告和日志，不再删除系统根目录和管理页面。共享的旧菜单精简、种子和校验脚本同步更新：系统页使用标准 ID 100–106，避免与会话权限 5201–5208 冲突，日志保持当前数据统计目录。

验证覆盖七个真实页面及接口、验证码缓存即时生效、只读配置角色、参数与部门基本操作；数据库验证空库、已删目录和不同系统根目录 ID 三种场景，检查重复初始化、自定义配置与授权保留。
