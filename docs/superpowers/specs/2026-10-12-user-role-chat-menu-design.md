# App 用户角色展示与会话列表入口精简

用户要求在 App 用户与创作者页新增用户角色列，普通注册用户默认为收购方，开通创作者资质后显示创作者；移除用户中心下的会话列表页。后续补充要求删除作者能力列和变更原因列。

采用现有作者能力作为业务角色的唯一依据：未开通显示收购方，开通显示创作者，关闭后恢复收购方。列表和用户详情同步展示。保留作者能力筛选与资质开通、关闭操作，更新资质后重新加载列表。变更原因不再作为表格列显示，变更时继续填写并保存操作记录。账号域 user_type 和管理端权限角色保持现有契约。

会话列表组件继续用于消息与公告的用户沟通页签。用户中心的独立会话列表路由改为隐藏跳转，旧地址进入 `/support/messages?tab=chat`。数据库初始化脚本将菜单 5201 改为消息与公告下的查询按钮权限，原按钮权限同时迁入，保留菜单 ID 和逐项角色授权；原会话查询角色补齐新页面和父目录授权。隐藏会话详情路由保留。

验证覆盖注册用户的默认展示、资质开通和关闭后的角色切换、详情一致性、删除作者能力列、移除独立侧栏入口和旧地址跳转，以及菜单迁移的空库初始化、旧库升级、受限角色权限和重复执行。业务会话与消息记录保持一致。
